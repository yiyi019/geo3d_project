# 基于平面地质图的智能化三维构建 (Intelligent 3D Geological Modeling MVP v3.0)

> **智能化三维地质建模系统**  
> **定位**：从平面地质图全自动与交互式协同构建三维数字地质体的 MVP 原型系统

---

## 一、 系统架构与 8 步向导式工作流

系统集成了图像处理、几何拓扑、地理信息与隐式地质场建模，采用 8 步向导交互界面（GUI）：

```
[步骤 1: 原始地质图输入] ──► 载入工区地质图 (JPG/PNG)，自适应计算物理比例尺 (1px = 2.0m)
       │
       ▼
[步骤 2: 黑白 Mask 提取] ──► 双边滤波去噪与色彩阈值分离，提取综合线划掩膜 (test_mask.png)
       │
       ▼
[步骤 3: 全自动连续 DEM] ──► 智能分离虚线等高线，定向切向缝合、OCR 赋高程与三角剖分，完全内置自足
       │
       ▼
[步骤 4: 边界断层粗细分离] ──► 距离变换自适应分离粗断层线 (~10px) 与细地层界线 (~2px)，滤除噪点
       │
       ▼
[步骤 5: 三维空间控制点] ──► 骨架测地有序化 + 结合 DEM 标高提取真实三维空间迹线 (surface_points.csv)
       │
       ▼
[步骤 6: 地层人工交互合并] ──► 画布高亮对应连通段，将断层错断界面 (Layer_1+2 ➔ Boundary_C_P) 合并重构真实层序
       │
       ▼
[步骤 7: 产状解算与突变质检] ──► 全要素空间切向产状解算，倾向突变检测标红，集成一键地学先验校准与邻域平滑工具箱
       │
       ▼
[步骤 8: 三维建模与工程分析] ──► GemPy 隐式势场求解，2D 剖面任意切割，虚拟钻孔综合柱状图，PyVista 3D 自由交互
```

## 二、 核心算法与技术创新

1. **下坡倾向顺坡方位角数学换算（修正 180° 反转）**：
   - 平面法向量 $\vec{n} = (n_x, n_y, n_z)$（$n_z > 0$），沿地层面最大下坡倾斜向量在水平面的投影为 $(n_x, n_y)$；
   - 采用标准地理方位角公式 $\text{Azimuth} = \arctan2(n_x, n_y) \pmod{360^\circ}$，确保倾向始终指向下坡顺坡方向，杜绝上坡逆坡反向。
2. **地学先验约束根治平切三角形外突**：
   - 针对单条 1D 露头线在走向侧向因深度数据欠约束拟合出的极缓（$4.8^\circ$）假倾角与深切冲沟相交产生的平切外突畸变；
   - 依据工区“北老南新”层序规律，引入统一南向中缓倾角（$170^\circ \angle 20^\circ$）先验，彻底消除外突飞地，保持三维地质体平整连续。
3. **全要素产状质检与一键校核工具箱**：
   - 断层（深红）、地层（深蓝）全要素产状与倾向箭头即时渲染；
   - 异常点黄色标牌高亮提示，提供 `[🌐 一键校准地层南倾 (20°根治外突)]`、`[🌐 应用至同地层全部点]`、`[🚀 修复异常突变 (对齐基准)]`，1 秒校准假产状。
4. **全自动虚线等高线连续 DEM 重建**：
   - 虚线段自动聚类、切向跨断层定向缝合、断口切向自适应 OCR 标高分配、矩形图框闭合周长一维场约束，杜绝边界收束与台地锯齿。
5. **工程分析与扩展应用**：
   - 任意起点/终点 2D 剖面实时切片渲染；
   - 虚拟钻孔添加、沿孔深三维网格岩性采样与综合柱状图绘制；
   - 真实大地坐标逆变换与曲面 VTK 网格导出。

## 三、 项目代码文件清单

```text
├── gui_app.py                      # 桌面图形交互系统 (wxPython + Matplotlib + PyVista)
├── compute_attitude.py             # 空间曲面多点切平面产状智能解算引擎 (SVD + 高斯加权)
├── model_engine.py                 # GemPy 隐式三维地质建模主计算引擎
├── output_customizer.py            # 剖面切割、钻孔采样柱状图与 VTK 导出扩展
├── demo_auto_dem.py                # 全自动连续平滑 DEM 重建引擎
├── extract_boundaries.py           # 地层边界线提取与粗细线划分离
├── extract_faults.py               # 断层构造线提取与骨架中心化
├── extract_surface_points.py       # 三维空间界面控制点提取
├── geo_segment.py                  # 地质图预处理与 CIE-LAB 颜色分区
├── project_config.json             # 建模工程配置参数持久化文件
├── surface_points.csv              # GemPy 标准地层界面控制点数据库
├── orientations.csv                # GemPy 标准地质产状数据库
├── requirements.txt                # Python 环境依赖清单
├── 启动界面.command                # macOS 一键双击启动脚本
├── PROGRESS.md                     # 项目技术全景与详细开发进展文档
├── test_guided_workflow.py         # 8 步工作流与突变检测单元测试 (9/9 通过)
├── test_comprehensive_regression.py # 全流程端到端深度回归测试 (4 组全过)
└── test_precision_and_persistence.py # 精度调节与模型持久化专项测试 (9/9 通过)
```

## 四、 快速启动与运行

### 1. 环境依赖安装
```bash
pip install -r requirements.txt
```

### 2. 启动桌面图形界面
- **macOS 双击**：直接双击 `启动界面.command` 即可启动；
- **命令行启动**：
  ```bash
  python gui_app.py
  ```

### 3. 运行自动化测试套件
```bash
# 1. 运行 8 步全流程与突变修正测试
python test_guided_workflow.py

# 2. 运行端到端综合回归测试
python test_comprehensive_regression.py

# 3. 运行精细度与持久化专项测试
python test_precision_and_persistence.py
```
